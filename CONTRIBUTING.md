You can develop the project locally by following the instructions below.

## Installation

Install the proper tools:
- Docker
- Dev Containers (VSCode Extension) [Learn More - Visual Studio Code Docs](https://code.visualstudio.com/docs/devcontainers/tutorial)

Next, fill out all the required secrets:

### /.env.local
```env
# Auth Secrets
AUTH_SECRET=
AUTH_CLIENT_ID=
AUTH_CLIENT_SECRET=

# Postgress Database
DB_NAME=
DB_HOST=
DB_USERNAME=
DB_PASSWORD=
```

Run the project in a dev container using VSCode.
